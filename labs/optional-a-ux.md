# 任意 A — レポートとアプリの UX を改善する

所要時間: 20〜30 分　／　前提: [Lab 06](06-powerbi-report.md)、[Lab 09](09-rayfin-app.md) 完了

本編で作ったレポートとアプリを、**数値の正しさを保ったまま**見やすく改善します。
デザインの変更でデータの意味を変えないよう、改善の前後で同じ数値が表示されることを必ず確認します。

## A-1. 改善方針を決める

🤖 **Copilot に入力**

```text
rpt_taxi_analysis と taxi-insights アプリの現在の画面構成を確認して、
タクシー運行管理者が「どの区で需要と売上が偏っているか」を 10 秒で把握できるように、
UX の改善案を 3 つ挙げて。配色はアクセシビリティ（WCAG AA のコントラスト）を満たして、
既存の数値や指標の定義は変えないで。
```

## A-2. レポートを改善する（Power BI）

🤖 **Copilot に入力**

```text
A-1 の改善案 1 と 2 を rpt_taxi_analysis に反映して。
変更前のレポートは rpt_taxi_analysis_v1 として残し、検証エラーが 0 件であることを確認してから公開して。
公開後、KPI が 37,948 件 / $687,602.60 / $11.92 のままか確認して。
```

## A-3. アプリを改善する（Rayfin）

🤖 **Copilot に入力**

```text
taxi-insights に A-1 の改善案を反映して。データの取得方法・権限・チャットの仕組みは変えないで。
型チェックとビルドが通ることを確認してから、教材の Rayfin 認証ラッパーで公開して。
```

🌐 **ブラウザ**: 公開 URL を開き、Lab 09 の 9-7 の確認表と同じ数値が表示されることを確認します。
